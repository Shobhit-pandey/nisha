Logo — 5 directions

Five logo directions for Shree KC Dada Memorial Hospital, each shown as a primary lockup plus reversed, 1-colour and favicon-size variants so you can judge how it holds up everywhere. These are clean concept marks — pick a direction (and mix is fine) and I’ll refine the winner into a final, pixel-perfect vector with all the production files.

Logo usage spec

Formats
SVG (master) → PNG, PDF, EPS for print
Clear space
Keep clear space ≥ height of the “S” in the wordmark on all sides
Min size
Icon 24 px digital / 10 mm print · full lockup 120 px / 30 mm
Variants
Full-colour · 1-colour · reversed (for dark) · mono black
Favicon / DP
Icon only (simplified mark), centred in a square
Colour
RGB/hex for screen · convert to CMYK + a Pantone for print

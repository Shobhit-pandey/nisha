NMC — keep it factual ✓

  • • Hospital + department, doctor name & real qualifications.
  • • Factual service list, address, hours, contact.
  • • Neutral, reassuring language; tasteful non-clinical motifs.

Never ✕

  • • Superlatives (“best”, “painless”), guarantees, testimonials.
  • • Discounts/free-camp bait, comparisons, before/after images.
  • • Any sex-determination wording (PCPNDT Act) — never.

Hindi: set Devanagari in a Unicode font (Noto Sans/Serif Devanagari — used here), never legacy Kruti Dev; outline/embed fonts in the print PDF and have a native speaker proof the laid-out artwork. Keep phone numbers in Western digits.
